# Visual assets

`route-illustration.png` is an AI-generated decorative image created for the Batch 2 lecture and companion page. It is not a geographic, transport-route, legal or entitlement map. The small topical pictograms on lecture frames are drawn by the renderer.

`fonts/NotoSans.ttf` and `fonts/NotoSansDevanagari.ttf` are Noto fonts; their SIL Open Font License texts are in `../licenses/`.
