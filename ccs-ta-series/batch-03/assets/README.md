# Visual assets

`claim-illustration.png` is a decorative AI-generated image created for the Batch 3 lecture and guide. It is not an actual ticket, government document, source or legal diagram. The topical pictograms on lecture frames are drawn by the renderer.

`fonts/NotoSans.ttf` and `fonts/NotoSansDevanagari.ttf` are Noto fonts; their SIL Open Font License texts are in `../licenses/`.
